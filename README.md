# U7+ Student Challenge 2027

## Publicar en GitHub Pages

1. Extrae el ZIP. Sube su contenido a la raíz de la rama `main` de tu repositorio. El archivo `index.html` y la carpeta `assets` deben quedar al mismo nivel.
2. En **Settings → Pages → Build and deployment → Source**, selecciona **Deploy from a branch**.
3. Selecciona **main** y **/(root)**, pulsa **Save** y abre la URL que aparece en esa pantalla cuando termine el despliegue.

El sitio ya está compilado. Conserva la carpeta `assets` completa. Para probarlo localmente, ejecuta `python -m http.server 8000` desde la carpeta extraída y abre `http://localhost:8000/`.
